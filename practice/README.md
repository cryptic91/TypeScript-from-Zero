# practice/

A completed run through the course — the exercises as they were actually typed, not as they were polished afterwards.

## How this differs from `solutions/`

`solutions/` holds the reference answer for each module: the shortest correct version, written to be read.

`practice/` holds a real working copy. The variable names are different, there are extra `console.log` lines, and some files try an idea two ways before settling. That is what the work actually looks like, and it is often more useful than a clean answer when you are stuck.

There is more than one correct answer to every exercise in this course. If yours differs from both folders and it runs, it is probably fine.

## Doing the course yourself

Copy an exercise here and fill it in. Leave `exercises/` untouched so the blank templates stay blank:

```bash
# macOS / Linux
cp exercises/02-variables.ts practice/

# Windows PowerShell
Copy-Item exercises\02-variables.ts practice\
```

Then run it:

```bash
npx tsx practice/02-variables.ts
```
